# WAVE LAB（音の可視化・分析）Ver1（卒論用 完成版）
アップロードするファイル（リポジトリの直下に、すべて置く）:
  index.html / style.css / sketch.js / nr.js / score.js / m.html / m.css / m.js
nr.js が、録音ファイルとマイクの両方のノイズ除去の計算本体です（PC版・スマホ版で共通）。

## 色譜（カラースコア）と音のまとまりJSON（記録ページ）
- 「色譜（楽譜画像）」: 時系列ログを、楽譜のように段に折り返した1枚のPNGにします（上: 色の帯 / 横棒: 重心の高さ・太さ=大きさ / 黒い点: 主要周波数 / ふち取り: 音のまとまり / 下: 純音らしさ）。保存範囲を指定していればその範囲だけです。
- 「音のまとまりJSON」（Ver1 では画面に出していません。score.js の WL_FEATURES.eventsJson を true にすると戻ります）: 途切れずに続く区間ごとの代表色・重心・平坦度などを保存します（場所名は任意）。世界地図に載せるときの元データです。
- 「色キャンバス」: 色と時間軸だけの画像です。無音のところは紙の色になります。
